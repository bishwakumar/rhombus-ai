# Observations

One file per test case: what was changed, what was expected, what happened, what the logs and chatbot said, and whether the fix worked, with the commands to reproduce it. Evidence is in [`evidence/`](evidence/).

Times are AEST (UTC+10) on 3 Oct and AEDT (UTC+11) from 4 Oct. Pipeline code throughout: `code_sha=3ca80b148200`.

**Severity:** High = wrong data delivered without warning, or a fix that claims to work but doesn't. Medium = visible failure that's hard to diagnose, or data dropped silently while values stay correct. Low = cosmetic.

**In short:** Rhombus stops when a column is **missing** (01, 02, 05). Every other change passes **silently**: blank dates (03), a dropped column (04), amounts 100× too high (06), wrong dates (07). The independent validator caught all of these except 44 swapped dates that no output check can see.
